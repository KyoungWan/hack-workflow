# CSV 탐색기 — Python 실행본

Python 3 표준 라이브러리 서버와 동봉된 브라우저 화면으로 실행한다. 실행 시 Next.js, SQLite, Node.js, npm 설치나 외부 CDN 접속은 필요 없다. 서버는 자동으로 시작하지 않는다.

## 실행

Next.js를 사용할 수 없는 환경에서만 이 폴더 전체를 새 작업 폴더에 복사한다. `static/`과 라이선스 파일도 함께 복사한다. 복사한 폴더에서 실제 CSV 폴더 경로를 지정하여 사용자가 직접 실행한다.

```sh
python3 server.py --data-dir "<실제 CSV 폴더 경로>" --port 3000
```

브라우저에서 `http://localhost:3000/data`를 연다. 다른 데이터 폴더는 `--data-dir "/실제/CSV/폴더"`로 지정한다. 폴더 안의 CSV를 재귀적으로 표시한다. 원본은 수정하지 않는다.

컨테이너 미리보기에서 외부 인터페이스 바인딩이 필요하면 `--host 0.0.0.0`을 추가하고 환경의 미리보기 주소로 접속한다. 프록시가 `/proxy/3000` 같은 접두 경로를 서버에 그대로 전달하면 `--base-path /proxy/3000`도 지정한다. 프록시가 접두 경로를 제거해서 전달하면 이 옵션은 사용하지 않는다. 보호된 시험환경의 미리보기에서 사용하며 이 앱 자체에는 인증이 없다.

## 기능

- 파일 선택, 전체 행·열 수, 검색 결과 수, 페이지 이동
- 전체 검색, 다중 열 필터의 포함/제외(NOT), 쉼표 OR·필터 간 AND
- 최대 3순위 문자/숫자 정렬, 열 너비 조절, 헤더·행 번호 고정
- 셀 원문 복사, 헤더·행 번호를 포함한 행 전체 복사, 권한 차단 시 수동 복사
- 사이드바 접기, 표 최대화와 Escape 복귀
- CSV BOM·따옴표·줄바꿈·중복 헤더·빈 값 보존, 오류 상태 안내

CSV 전체를 브라우저 메모리에서 처리한다. 큰 파일은 처리 지연이나 메모리 부족이 생길 수 있으므로 작은 파일부터 확인한다. 파일을 다시 선택하면 원본을 다시 읽는다.

## 검증·개발

서버를 시작하지 않는 Python 검사는 복사한 폴더에서 `python3 -m unittest discover -s . -p 'test_*.py'`로 실행한다. 브라우저 소스 수정 후에만 이 폴더에서 `npm install`, `npm test`, `npm run build`를 사용한다. 일반 실행에는 필요 없다.

CSV 파서 라이선스는 `CSV-PARSE-LICENSE`에 포함되어 있다. 브라우저 번들에도 동봉 코드의 라이선스 주석을 유지한다.
